# ・ Projeto Interdisciplinar: Website Pessoal

[Github Pages](https://jguilherrme.github.io/projeto-portfolio/)

## ・ Sobre o Projeto

Projeto desenvolvido durante o curso de Sistemas para Internet na Faculdade de Tecnologia Prof. José Camargo (Fatec Jales), como parte de uma atividade acadêmica interdisciplinar.

O projeto consiste em um website pessoal desenvolvido com foco na apresentação de informações, organização de conteúdo e aplicação de conceitos fundamentais de desenvolvimento front-end.

A proposta foi aplicar conceitos de **HTML semântico, CSS, arquitetura de informação e design responsivo**, buscando construir uma interface organizada, acessível e visualmente consistente.

## ・ Estrutura do Projeto

### `index.html`

Documento principal responsável pela estrutura e organização do conteúdo do website.

### `assets/`

Diretório destinado aos recursos visuais utilizados no projeto, como imagens, ícones e elementos gráficos.

## ・ Conceitos Aplicados

* HTML5 semântico
* CSS3
* Design responsivo
* Arquitetura de informação
* Organização de conteúdo
* Estruturação de interfaces web

## ・ Identidade Visual

A interface foi desenvolvida buscando manter uma identidade visual consistente, utilizando organização hierárquica dos conteúdos e elementos visuais para facilitar a navegação e a apresentação das informações.
